## Suggested Devpost text

**Name:** FUSE  
**Tagline:** Don't be holding it. A 3D real-time multiplayer bomb-tag arena.

**Built with:** JavaScript, Node.js, Express, Socket.io, Three.js, Web Audio API

**Description:**

FUSE is a 3D browser arena where 2–6 people share one live bomb. Bump someone to pass it. Throw it if you must. When the timer hits zero, whoever is too close is out. First to 3 rounds wins.

The design bet is social: create a room, send a link, play together. No accounts. Judges can jump in and play with you instead of only watching a video.

**Who it's for:** friends, classmates, and anyone who will open a link and stay for one more round.
